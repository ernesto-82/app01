## IMPLANTACION DE APLICACIONES WEB

Tres ejercicios muy basicos de PHP integrados en una web app muy sencilla

## Ejercicios

1.- **Calculadora** 
2.- **Mayoría de edad** — indica si alguien es mayor o menor de edad.
3.- **Números** — imprime del 1 al numero introducido y del numero introducido al 1.

## Cómo ejecutarlo

1.- Servir la carpeta `app01/` con un servidor con PHP (Apache, Nginx + PHP)
2.- Abrir `index.html` en el navegador.
3.- Elegir un ejercicio y rellenar el formulario.

## Tecnologías

- HTML5
- Bootstrap
- PHP
